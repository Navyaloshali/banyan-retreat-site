# The Banyan Farms Website

## Build
- Create a polished single-page farmhouse website with sticky navigation, mobile menu, full-screen photographic opening, and smooth anchor navigation.
- Build every requested section: farm introduction, day timeline, stays, grouped activities, food, bonfire, packages, masonry gallery, testimonials, contact form, final invitation, and footer.
- Use a warm countryside design system with forest green, sage, cream, brown, and terracotta; pair an editorial serif with a clean sans serif.

## Structure
- Keep editable copy, packages, activities, stays, gallery items, and testimonials in a dedicated content file.
- Split the interface into reusable section and card components instead of one large page file.
- Use generated local imagery so the final site has a cohesive, realistic farmhouse identity and no fragile remote placeholders.

## Interaction and quality
- Add restrained reveal motion, image zoom, package hover states, a scroll-aware navigation bar, and a calm mobile menu transition.
- Make the enquiry form validate required fields and show a local success state without sending data.
- Verify desktop and mobile rendering, interactions, metadata, and the final build state.
