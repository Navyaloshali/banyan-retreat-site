# Banyan Retreat Site

Build a complete, modern, responsive website for a countryside farmhouse getaway called:

THE BANYAN FARMS

Tagline:

"Escape the city. Find your wild."

ABOUT THE BUSINESS:

The Banyan Farms is a small, peaceful countryside farmhouse and experiential getaway designed for families, friend groups, couples, and small groups. Guests can stay overnight, enjoy homemade/farm-style food, participate in fun outdoor adventure activities, play traditional and modern games, explore nature, relax around a bonfire, and spend quality time away from the city.

The website should feel like a REAL boutique farmhouse business, not a corporate hotel or a huge luxury resort.

DESIGN DIRECTION:

- Rustic, warm, natural and youthful

- Premium but approachable

- Strong countryside/farm aesthetic

- Lots of high-quality nature and farmhouse photography

- Earthy color palette: deep forest green, muted sage, warm cream, earthy brown, subtle terracotta

- Large typography and strong visual hierarchy

- Rounded cards with subtle shadows

- Organic shapes and gentle curves

- Plenty of whitespace

- Smooth animations and micro-interactions

- Use a beautiful serif font for major headings and a clean sans-serif font for body text

- Avoid an overly complicated or flashy design

- Do NOT make it look like a generic hotel booking website

TECH STACK:

- React

- Vite

- Tailwind CSS

- JavaScript or TypeScript

- Lucide React icons

- Component-based architecture

- Keep all content/data easy to edit from separate files where practical

- No backend required for the MVP

- No authentication required

- No database required

- Use placeholder images from Unsplash or another reliable image source, but structure the code so I can easily replace them with my own farmhouse photographs later.

UX / ANIMATION REQUIREMENTS:

- Smooth scrolling between sections

- Fade-in and slide-up animations when sections enter the viewport

- Subtle image hover zoom

- Button hover animations

- Navbar changes appearance on scroll

- Smooth mobile menu animation

- Package cards should have subtle hover effects

- Avoid excessive animations

- Page should feel calm and premium

RESPONSIVE DESIGN:

The website must work properly on:

- Desktop

- Laptop

- Tablet

- Mobile

Pay special attention to mobile typography, navigation and image proportions.

CODE QUALITY:

IMPORTANT:

I will personally modify this project later in VS Code.

Therefore:

- Keep components modular

- Do not put the entire website into one huge file

- Create reusable components such as Navbar, Hero, SectionHeading, ActivityCard, StayCard, PackageCard, Gallery, Footer, etc.

- Keep text/content in easy-to-edit data structures where practical

- Use meaningful component and variable names

- Avoid unnecessary dependencies

- Add comments only where they genuinely help

- Keep the code beginner-friendly and readable

- Make it easy to replace placeholder images

- Do not hardcode repeated UI unnecessarily

Create the complete working website, not just a design mockup.
